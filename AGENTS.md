# SquadPad agent guide

## Layout

One repo for everything. Do not split parts into separate repositories: `squadpad-native` was an earlier standalone repo and the native module sources were lost when it was folded in here.

| Path | What | Install / test |
|---|---|---|
| `web/` | Browser controller (plain HTML/CSS/JS) + Tauri desktop host | root `npm install`; `npm run test:web` |
| `relay/` | WebSocket relay on Fly.io | root `npm install` |
| `native/` | Expo app (iOS/Android) | `cd native && npm install`; `npm run typecheck`; `npm test` |
| `docs/PROTOCOL.md` | Wire format shared by all three | |

## Rules

- The BombSquad wire format is implemented three times: `web/src/js/protocol.js`, `native/src/protocol/`, and `relay/server.js`. Change them together and update `docs/PROTOCOL.md`.
- Relay players speak the protocol in `web/src/js/connection.js`: send `{"type":"join"}`, wait for `joined`/`ready`, then send raw 3-byte states (`[buttons, h, v]`); the desktop host owns the BombSquad session. `native/src/connection/ws-connection.ts` mirrors it; change both together and test against a real host and the relay.
- `native` is deliberately not an npm workspace. It keeps its own `native/package-lock.json`; adding it back to the root `workspaces` breaks `npm ci` and EAS builds.
- Upgrade Expo with `npx expo install expo@^<sdk> && npx expo install --fix`, then `npx expo-doctor`. `jest` and `@types/jest` are excluded from Expo version checks because tests run through `ts-jest`, not `jest-expo`.
- `native/ios/` and `native/android/` are generated by `npx expo prebuild` and gitignored. Never put hand-written code there.
- Custom native modules live in `native/modules/<name>/{ios,android,src}`. Their Swift and Kotlin sources MUST be committed. Before committing native work, confirm with `git ls-files native/modules` that every `ios/` and `android/` file is tracked.
- The app does not run in Expo Go because of those modules. Use `npx expo run:ios`, `npx expo run:android`, or an EAS development build.
- iOS UDP uses one bound BSD socket for send and receive (replies come back to the sending port). iOS rejects `255.255.255.255`; discovery uses the subnet broadcast from `getBroadcastAddress()`. Broadcast on a real device requires the `com.apple.developer.networking.multicast` entitlement.
- Android UDP: `DatagramSocket.receive()` and its option setters are `synchronized` on the socket. Set options before the receive thread starts and keep `soTimeout` on the receive loop, or a setter called from JS deadlocks the JS thread.
- iOS 27: keep `expo-build-properties` `ios.enableSceneSupport: true` while on SDK 57. Without it, Xcode 27 builds crash at launch. Remove it on SDK 58, where scenes are the default.
